# Sable downloads

Sable is a lightweight native Windows music player, built with Rust and Slint.

Official releases: https://github.com/subliminalsidkthemeaning/Sable/releases

Stable installer target: https://github.com/subliminalsidkthemeaning/Sable/releases/latest/download/Sable-Setup-x64.exe

Choose the installer or extract the complete versioned portable ZIP and run SableMusic.exe. Check release SHA256 checksums. Windows installers are unsigned.

This repository contains official distribution artifacts and public documentation. Application source is maintained separately in a private repository. Historical releases and assets are retained. See LICENSE, NOTICE.md and THIRD_PARTY.md for upstream attribution and third-party notices.
